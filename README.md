# CS-Custom

CloudStream3 custom repository currently publishing the `KissKH` provider.

## Add This Repo to CloudStream

Use this repository URL inside CloudStream:

```
cloudstreamrepo://raw.githubusercontent.com/NovaCommand/CS-Custom/personal_build/repo.json
```

Direct `repo.json` link:

```
https://raw.githubusercontent.com/NovaCommand/CS-Custom/personal_build/repo.json
```

Main plugin index (`plugins.json`):

```
https://raw.githubusercontent.com/NovaCommand/CS-Custom/personal_build/plugins.json
```

## Important: Branch Layout

All active development **and** published artifacts live on the **`personal_build`** branch, not `master`.

> ⚠️ The GitHub repo homepage shows file timestamps from the **default branch (`master`)**.  
> Files like `KissKH.cs3` may appear outdated there even when the plugin was just rebuilt.  
> Always check `personal_build` or the live raw URL above for the current artifact state.

## CI/CD — How the Plugin Gets Built

Every push to `personal_build` (that touches source files) triggers the `Build` GitHub Actions workflow:

1. Checks out `personal_build`
2. Sets up JDK 21 (Temurin) + Android SDK
3. Runs `./gradlew make makePluginsJson`
4. Copies the built `KissKH.cs3` to the repo root and patches `plugins.json` branch references
5. Commits and pushes both files back to `personal_build`

**Do not manually commit `KissKH.cs3` or `plugins.json`** — they are always generated and published by CI.

## Build Commands (Windows PowerShell)

```powershell
./gradlew.bat build
./gradlew.bat derle
./gradlew.bat :KissKH:build
./gradlew.bat clean
```

Use `--info` or `--stacktrace` for debugging build/packaging issues.

> **Note:** Do not add `org.gradle.java.home` to `gradle.properties` with a machine-specific path.  
> It will break CI on Linux runners and on any other machine. Leave it unset.

## Project Layout

- `KissKH/src/main/kotlin/com/byayzen/KissKH.kt` → provider logic (`getMainPage`, `search`, `load`, `loadLinks`)
- `KissKH/src/main/kotlin/com/byayzen/KissKHPlugin.kt` → plugin entrypoint (`load(context: Context)` — `context` parameter is required)
- `KissKH/src/main/kotlin/com/byayzen/SubDecryptor.kt` → subtitle decryption helper
- `repo.json` and `plugins.json` → CloudStream repository and plugin index metadata (auto-generated by CI)
- `.github/workflows/build.yml` → CI/CD pipeline (triggers on `personal_build` pushes)
